# 알콩약콩 데이터셋

식약처 DUR 데이터로 만든 일반의약품 복약 안전 판정 QA 샘플입니다.

## 파일

| 파일 | 설명 |
|---|---|
| `train.jsonl` | 학습용 800문항 (UTF-8, 한 줄당 JSON 한 개) |
| `val.jsonl` | 검증용 100문항 (UTF-8, 한 줄당 JSON 한 개) |
| `test.jsonl` | 테스트용 100문항 (UTF-8, 한 줄당 JSON 한 개) |
| `stats.json` | split별 구성 수치 요약 |

## 컬럼

| 컬럼 | 설명 |
|---|---|
| `id` | 샘플 ID (예: `val_0001`) |
| `category` | 금기 유형: `병용금기` / `임부금기` / `특정연령대금기` / `기타` |
| `question` | 사용자 질문 |
| `evidence` | 판정 근거가 되는 DUR 기록 (제품 성분, 금기 내용) |
| `reference` | 모범 답변 |
| `response_type` | 응답 유형: `설명` / `추가 질문` / `판단 보류` |
| `source_rule_id` | 근거가 된 원천 DUR 기록 ID (근거 없음은 `NOEVID`) |
| `split_group_id` | split 간 누수 방지용 그룹 ID (같은 그룹은 한 split에만 들어감) |

## 구성

| split | 문항 | 병용 / 임부 / 연령 / 기타 | 설명 / 추가 질문 / 판단 보류 | 그룹 |
|---|---|---|---|---|
| Train | 800 | 373 / 240 / 27 / 160 | 384 / 184 / 232 | 45 |
| Val | 100 | 35 / 30 / 15 / 20 | 48 / 23 / 29 | 9 |
| Test | 100 | 35 / 30 / 15 / 20 | 48 / 23 / 29 | 9 |

- Train의 응답 유형 비율은 Val/Test의 8배로 맞췄습니다.
- 그룹마다 `설명` / `추가 질문` / `판단 보류` 짝을 먼저 만들고, 나머지 수량을 나눠 배정했습니다.
- `기타`는 DUR 근거를 바탕으로 한 일반 질문입니다. 근거는 금기 기록 전체, 제품 성분만, 빈 값 세 가지 형태입니다.

### Train 구성 참고

- Val/Test에 쓰인 그룹과 제품명은 Train에서 제외했습니다. 그래서 만들 수 있는 그룹이 45개(병용 19, 임부 21, 연령 5)입니다.
- 연령금기는 남은 원천 기록이 적어 제품당 3문항씩 27문항만 만들었고, 모자란 수량은 병용금기로 채웠습니다.
- 에티닐 에스트라디올은 원문 사유가 "피임제" 한 단어뿐이라 임부금기 문항을 9개로 제한했습니다.

## 주의

- **Val/Test는 평가용 동결본입니다. 내용을 수정하지 마세요.**
- Train은 Val/Test를 그대로 둔 채 같은 시드(`20261122`)로 생성했습니다. Val/Test와 그룹, 원천 기록, 질문, 제품명이 겹치지 않습니다.
- 원천 DUR 파일(`dur_*.json`, `dur_*.jsonl`)은 용량과 이용 약관 문제로 repo에 올리지 않습니다.

## 재생성 방법

시드가 고정되어 있어 같은 원천 파일로 같은 결과가 나옵니다. 스크립트는 Train만 새로 만들고, Val/Test는 `data/`의 동결본을 그대로 복사합니다.

```bash
python3 scripts/build_dataset.py --data-dir <원천 파일 폴더> --out-dir out
python3 scripts/validate_dataset.py out
```
